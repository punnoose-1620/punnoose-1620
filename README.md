# Hi, I'm Punnoose K Thomas 👋

**AI Engineer at Volvo Cars** — building enterprise AI agents on Microsoft Azure and Copilot Studio.

I recently completed my **MSc in AI Engineering** at Jönköping University. My master's thesis focused on designing and empirically evaluating agentic LLM workflows with structured function calling for internal knowledge retrieval in an automotive context.

My background spans Android, full-stack development, and production AI systems — including agentic LLM platforms at Patent Gap AI and AI/backend work at Norditech AB. That foundation shapes how I build today: reliable architecture, grounded responses, and tools that stakeholders can actually use.

I'm especially interested in **agentic AI**, **retrieval-grounded workflows**, and deploying LLM solutions responsibly in enterprise environments.
